May 19-24 Designing base.
I decided on a circular base made up of multiple parts made up of its own sub parts. The mase is compries of the static and moving base. The static base is made of 3 parts. the flat base plate, outer ring, innce circle. The static base bottom plate has multiple features that help the moving base to freely rotate like a thrust bearing and a bb track. Next is the moving base. The moving base is made up of multile parts also. a bearing stack, spacer, gear.

June 4th start coding
i started to code part of the arm today, on the arduino side i have defined all of the pins, Direction, Enable, Steps. I also have the enable function, so if a later made enable button is presed then the steppes will be enabled and ready to controlled, if not presed then the arm will not be able to be controlled. This is partly a safety feature, if you do not mean to move the arm controller inputs will not control the arm. I am in FRC (first robotics competition) and i like the look of the FRC dashboard that we use to controll our robots so i would like to maka an application that looks similar and has some of the same features, this enable feature is one of many i would like to incorporate.
